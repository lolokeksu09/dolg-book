# История изменений

## v1.0 — первая публичная версия (06.11.2026)

- Опубликован универсальный комплект правил для совместной работы с ИИ-агентом над проектом.
- Уточнено, что ZIP можно прикрепить к новому чату без распаковки; распаковка нужна, только если среда не принимает архив или агент работает непосредственно в файловой системе проекта.
- Добавлен единый блок «Первый запуск»: последовательность действий и три сценария — только идея, пустой проект, существующий код.
- Для нового проекта закреплён один минимальный сквозной пользовательский сценарий вместо старта с полной архитектуры и обязательного создания всех документов.
- Уточнён выбор стека: решение владельца сохраняется; при отсутствии решения предлагается один обоснованный основной вариант без лишнего сравнения и зависимостей «на будущее».
- `PROJECT.md` оформлен как карточка старта: цель, первая работающая версия, критерий готовности, границы, стек и разрешения; незаполненные необязательные поля не блокируют независимую работу.
- Добавлена немедленная проверка нового каркаса: применимые установка зависимостей, сборка, запуск, `.gitignore`, отсутствие секретов и фиксация реальных команд.
- Описаны режимы Light/Full, уровни L1–L5, независимые статусы, исключения из обязательных проверок и границы разрешений.
- Шаблоны PLAN и VERIFICATION связывают первый сценарий и проверки каркаса с доказательствами; таблица выбора L1–L5 дополнена новым проектом/каркасом.
- Итоговый ZIP прошёл статическую самопроверку 8/8; она подтверждает целостность и согласованность комплекта, но не является тестом поведения ИИ-агента.
