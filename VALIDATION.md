# Проверка стандарта

## Статус версии v1.0

**Первая публичная версия.** Статическая проверка ссылок, шаблонов и ZIP подтверждает целостность и базовую согласованность комплекта. **Она не подтверждает, что реальный ИИ-агент будет соблюдать правила**, и не заменяет проверку поведения на конкретной модели, в конкретной среде и на реальных задачах.

### Статическая проверка

**06.11.2026, проверка v1.0:** `python tools/check_standard.py Project-Workflow-Standard-v1.0.zip` — **8/8 PASS** на итоговом ZIP. Проверены целостность ZIP (CRC), состав комплекта, 15 Markdown-файлов и UTF-8, локальные ссылки, согласованность обозначений версии, основные нормативные маркеры, первый запуск, карточка проекта, выбор стека и проверка каркаса. Текстовые проверки **не доказывают смысловую непротиворечивость** или фактическое поведение агента.

Эта проверка **не является** тестом поведения ИИ-агента, L4/L5 пользовательского приложения или независимым сравнением разных версий.

## Ручная проверка применимости

Ниже — разбор типовых ситуаций по тексту комплекта. Он показывает, что нужное действие следует из документов и не требует чтения всех шаблонов. Это не независимый запуск агентов и не измерение экономии токенов.

| Ситуация | Действие по документам | Основание |
|---|---|---|
| Изменить цвет кнопки | Целевая правка и просмотр новой сборки; без большого плана и всех пяти уровней | [AGENTS.md](AGENTS.md): исполнение; [TESTING-LEVELS.md](TESTING-LEVELS.md): выбор |
| Исправить абзац документации | Проверить факты и ссылки; не запускать приложение только ради номера уровня | [TESTING-LEVELS.md](TESTING-LEVELS.md): выбор |
| Начать проект с идеей без стека | Определить один сквозной сценарий, предложить один обоснованный стек и первую проверяемую версию | [README.md](README.md): первый запуск |
| Доработать проект с чужим diff | Сохранить пользовательские изменения; изолировать конфликтующую область | [AGENTS.md](AGENTS.md): исполнение; [README.md](README.md): подключение комплекта |
| Исправить проверку чужого доступа | Воспроизвести дефект; проверить разрешённый и запрещённый сценарий | [TESTING-LEVELS.md](TESTING-LEVELS.md): выбор |
| База данных недоступна | Продолжить независимую работу; отметить интеграцию недоступной, не выдавая mock за БД | [AGENTS.md](AGENTS.md): проверки; [TESTING-LEVELS.md](TESTING-LEVELS.md): доказательства |
| UI собирается, браузер недоступен | Сообщить об отсутствии визуальной проверки и фактической альтернативе | [AGENTS.md](AGENTS.md): проверки |
| Публикация уже явно разрешена | Довести разрешённую поставку и L5 без повторного запроса в том же объёме | [AGENTS.md](AGENTS.md): самостоятельность |
| Публикация не разрешена | Подготовить конкретный кандидат и доказательства, затем запросить недостающее разрешение | [AGENTS.md](AGENTS.md): самостоятельность |
| Обязательная job skipped | Не объявлять gate успешным; исправить причину либо зафиксировать допустимое исключение | [TESTING-LEVELS.md](TESTING-LEVELS.md): статус |
| Старый снимок показывает незавершённый уже выпущенный этап | Сверить код, PR и CI, продолжить реальное незавершённое | [CONTINUATION](templates/CONTINUATION.md) |
| В проекте свои L-уровни или нет Git | Сохранить местные определения; для артефакта использовать версию или хеш | [TESTING-LEVELS.md](TESTING-LEVELS.md): сопоставление и доказательства |

**Ограничение:** этот разбор выполнен вручную по тексту. Он не доказывает, что конкретная модель и среда всегда выберут указанное действие. Реальное поведение проверяется на конкретном проекте с сохранением команд, версий и доказательств.
