# Public licensed candidate (owner acceptance only)
Explicit opt-in Gradle property raschetPublicLicenseKey sets mandatory license on the existing release package, version 0.31.0-beta.1/code 36 (greater than published RC code 35). Default release and private staging remain unchanged, and release-request.json is not changed. The profile uses only https://license.ventrylab.top and Android system trust, no private CA, no redirects and no cleartext. The pinned raw Ed25519 verification key must be the existing server public key, not the signing seed. Existing license policy, local data and package/signature scheme remain unchanged. Mandatory subscription blocks new debt, not viewing, payments or backups.

PR CI builds an unsigned candidate with a public test vector and validates native ABI, alignment, manifest, generated build configuration and invalid inputs. After merge, owner manually runs "Raschet public licensed candidate" on main with the existing server's public key; the existing pinned release certificate and signing secrets are reused. The artifact is not a published release and is not authorized for customer distribution. Real HTTPS, activation and refresh, expiry, no-network handling and non-destructive upgrade from an isolated copy of the previous signed APK are separate acceptance gates. Back up the book before physical-device tests. Do not input private keys or actual activation codes into CI. Do not pin a temporary staging key in a commercial APK. Ventry Delivery's approved APK metadata must be updated only after acceptance; no live deployment in this PR.
