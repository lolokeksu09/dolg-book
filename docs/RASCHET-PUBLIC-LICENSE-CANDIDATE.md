# Единая сборка «Расчёта»

Пользовательский APK с пакетом `dev.ventry.raschet` включает локальную книгу, лицензию, ручные и автоматические зашифрованные облачные копии, Rust JNI. Параметры берутся из [release-profile.properties](../android/release-profile.properties). Публичный ключ Delivery взят из ранее проверенного подписанного кандидата. Release использует HTTPS `license.ventrylab.top` и системное доверие Android. Debug и закрытый стенд используют отдельные тестовые пакеты.

Подписанный APK для приёмки собирает [Raschet public licensed candidate](../.github/workflows/raschet-public-licensed-candidate.yml) после изменения профиля в `main` или ручного запуска на `main`. Проверяются прежний сертификат, пакет, версия, лицензия, сервис автокопирования, четыре Rust ABI и выравнивание. На PR этот же профиль собирается без release-подписи. Прежние GitHub-релизы остаются доступны в истории публикаций.

Для передачи покупателям сначала пройти [физическую приёмку](RASCHET-ACCEPTANCE.md), затем отдельно утвердить артефакт и обновить метаданные в Ventry Delivery. Подписанная сборка из Actions предназначена для приёмки владельцем.
