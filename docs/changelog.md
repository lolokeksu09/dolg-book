# v0.2.0

- Редактирование имени и телефона клиента без потери истории.
- Отмена последней действующей операции клиента: отдельная запись с причиной вместо удаления. Просрочки и месячные оплаты исключают отменённые операции.
- Крупный режим: увеличенные имена, суммы, кнопки и поля форм. Выбор сохраняется на устройстве.
- Название магазина в настройках, боковой панели и выписке.
- Совместимый импорт копий формата 1; формат 2 сохраняет ссылки отмен.
- CSV содержит операции отмены, ID исходной записи и ID отменяемой записи.

Проверка: 7 тестов модели. В браузере проверены отмена тестовой оплаты 1 000,50 ₽ с восстановлением остатка 2 700 ₽, сохранение исходной записи и причины отмены, переименование клиента без изменения долга, включение крупного режима. Проверка выполнена на локальном предпросмотре, данные вымышлены. На физическом Android-планшете не проверено. Серверная синхронизация пока отсутствует.
