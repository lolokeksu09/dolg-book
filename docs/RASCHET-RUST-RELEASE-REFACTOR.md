# Расчёт: интеграция Rust и рефакторинг границы внешних операций

База main: `2dab01e206b7cb3296249311cb06129738658428`. Публичный signed RC2: `36951ee81d3c408a63d27c1181dbb2df8bf851b4`. Владелец разрешил интеграцию Rust в main и рефакторинг. Не менять package id, подпись, схему SQLite, формат копий или существующие финансовые правила.

## Требования и критерии

| ID | Изменение | Проверка |
|---|---|---|
| RUST-01 | Release всегда включает ранее проверенный JNI correction engine; debug Kotlin-only по умолчанию, native debug опционален. | Все четыре ELF ABI, 16 KiB alignment, обязательная сборка до подписи, запрет релиза без .so. |
| RUST-02 | Kotlin/Rust parity на каждом исправлении, ошибки/расхождение не допускают запись. | Общие fixtures, JNI host, Android JNI instrumentation и транзакционный тест; signed UI correction smoke перед публикацией. |
| FILE-01 | REQUEST_ANALYTICS=109; 106 остаётся исключительно credential OPEN. | Уникальность запросов, правильная маршрутизация и фактический экспорт CSV/PDF из синтетической книги. |
| FILE-02 | PendingFileRequests владеет параметрами SAF, MainActivity только запускает picker и подтверждение импорта. | Сохранение параметров в Bundle; успех, отмена, отказ после блокировки, пустой URI, повтор результата. |
| FILE-03 | Один CsvText для строк CSV полной книги и статистики. | Префиксы формул после whitespace, переводы строк и кавычки; числовые колонки статистики не превращаются в текст. |
| QA-01 | Все прежние обязательные CI, включая native preview и unsigned release packaging, должны пройти на актуальном SHA до merge. | Статусы Actions и результаты тестов, не только написанный код. |

## Доказательство дефекта до исправления

В исходном MainActivity `REQUEST_ANALYTICS=106`, в BookPrivacy `OPEN=106`. Проверка исходных констант дала два совпадающих значения. onActivityResult проверял credential первым: результат SAF попадал в обработчик разблокировки и возвращался до создания FileTask.Analytics. Это подтверждено кодом; новый сквозной тест системного picker на физическом устройстве пока не выполнен. Общий unit-тест роутинга и инструментальный тест фактической записи CSV/PDF добавлены.

## Границы

- Rust активирован именно для исправления/отмены в пределах существующего correction JNI ABI; другие Rust-проекции остаются контрактными реализациями, не подключены к Android JNI. Kotlin сохраняет проверку равенства, SQLite — транзакции.
- Имена версии, package id и сертификат не меняются в этой ветке. Публичный RC2 остаётся неизменным. Новый подписанный кандидат — отдельная поставка с новой версией/тегом.
- Сохранность дополнительных метаданных клиентов при переносе, стабильная историческая дата, дальнейшее выделение UI/запросов SQLite из MainActivity, общая дизайн-система и тест физического обновления остаются открытыми задачами аудита.
- На момент создания PR новые проверки ещё не пройдены. Не считать релиз готовым до CI и проверки подписанного APK.
