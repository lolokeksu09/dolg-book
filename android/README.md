# Расчёт · Android APK v0.2.0 (пилот)

Это устанавливаемое Android-приложение с **автономной локальной долговой книгой внутри APK**. При открытии показываются клиенты, долги, оплаты, выписки и история из существующего `dist/` проекта, без внешнего браузера и без сети. Данные сохраняются в private storage Android WebView для этого пакета (`localStorage`).

Вверху есть отдельная кнопка **«Общая книга»**. Она открывает защищённый серверный вход в системном браузере, как и раньше: пароль Keycloak **не вводится внутри WebView**. Адрес сервера задаётся при сборке через `raschetOrigin`. **Локальная и общая книги не синхронизируются**: операции из локальной книги не попадают автоматически на сервер, и наоборот. Импорт JSON v1/v2 доступен для переноса из предыдущей версии; это ручное действие с подтверждением замены.

### Функции

- Локальный учёт из `dist/`: клиенты, долги, частичные оплаты, остатки, история, сроки и отмены.
- Полноценная офлайн-работа без INTERNET-соединения.
- Импорт JSON из системного выбора документов, экспорт JSON/CSV через системный выбор места сохранения.
- Печать выписки и сохранение PDF системным сервисом печати.
- Крупный режим для планшета.
- Защищённая загрузка встроенных ресурсов `WebViewAssetLoader` по отдельному HTTPS origin, внешние страницы не выполняются внутри приложения.
- Отдельная кнопка общей серверной книги через системный браузер; доступность сервера и авторизация должны проверяться отдельно.

### Сборка

Нужны JDK 17, Android SDK 35, Gradle 8.11.1. Из корня репозитория:

```sh
node --test tests/ledger.test.js tests/android-bundle.test.js
gradle -p android lintDebug assembleDebug --no-daemon \
  -PraschetOrigin=https://raschet.135-106-227-179.sslip.io
```

Готовый APK: `android/app/build/outputs/apk/debug/app-debug.apk`, Android 8.0+ (`minSdk 26`), пакет `dev.ventry.raschet.debug`, **отладочная подпись**. Этот пакет устанавливается отдельно от ранее выпущенных APK с другим ID; не пытайтесь заменить существующий релизный APK поверх без проверки подписи и миграции.

Автоматическая сборка: [Android APK](../.github/workflows/android.yml) через GitHub Actions, результат в артефакте `Raschet-debug`. Если `RASCHET_ORIGIN` задан в переменных репозитория, он заменяет технический адрес по умолчанию. Секреты Keycloak/SSH не включаются в APK.

### Ограничения и сохранность данных

- Удаление приложения или очистка его данных удалит локальную книгу; экспортируйте JSON-копию заранее.
- Резервная копия JSON содержит имена, телефоны и суммы **в открытом виде**. Храните её в защищённом месте.
- Автоматические серверные копии, сотрудники в офлайне, восстановление между устройствами и платный релиз здесь не заявлены.
- Пилотный сервер может быть недоступен или потребовать повторной настройки Caddy после обновления Ventry.
- В CI проверяются сборка, lint и состав APK; установка на физический Android и реальный вход в Keycloak требуют отдельной приёмки.
