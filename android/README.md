# «Расчёт» · Android 0.3.0 (нативная версия)

**Нативный Android UI, а не WebView:** экраны, навигация, формы, история и ввод долга строятся средствами Android Views. Данные находятся в приватной SQLite. Внутри APK нет HTML, JavaScript, WebView, JS-моста и файлов веб-сайта.

Доступно: сводка по долгам и просрочке, поиск клиентов, создание и изменение контактов, новые долги и оплаты, частичное погашение, сроки возврата, отмена последней действующей операции с причиной, история и фильтры, резервная копия JSON/CSV, импорт ранее выгруженных JSON v1/v2 с проверкой и подтверждением замены. На планшетах от 720dp применяется боковая навигация. Отдельный переход «Общая книга онлайн» в настройках открывает внешний браузер — **не смешивается с локальным учётом**.

## Очень важно перед обновлением с v0.2

Версия v0.2 хранила книгу внутри **WebView localStorage**. Версия v0.3 использует **SQLite**. Автоматического переноса между ними нет.

**Сначала в установленной v0.2 выгрузите JSON, сохраните его вне приложения, и только после этого обновляйте APK!** В новой v0.3 откройте «Настройки → Восстановить из JSON» и выберите сохранённый файл. Восстановление заменяет текущую книгу после подтверждения. Предыдущая v0.2 и новая v0.3 используют один debug package \`dev.ventry.raschet.debug\`; при установке поверх системные данные могут сохраниться, но v0.3 не читает хранилище WebView.

Удаление приложения/очистка данных уничтожит локальную SQLite-книгу. Автоматические копии Android и перенос на другое устройство отключены. JSON/CSV содержит имена, телефоны и суммы в открытом виде. Храните копии защищённо.

## Сборка

JDK 17, Android SDK 35, Gradle 8.11.1.

\`\`\`bash
node --test tests/ledger.test.js tests/android-bundle.test.js
gradle -p android lintDebug assembleDebug --no-daemon -PraschetOrigin=https://raschet.135-106-227-179.sslip.io
\`\`\`

APK: \`android/app/build/outputs/apk/debug/app-debug.apk\`, Android 8.0+, пакет \`dev.ventry.raschet.debug\`, отладочная подпись. GitHub Actions workflow \`Android APK\` сохраняет артефакт \`Raschet-native-debug\`.

## Границы

Эта сборка — автономная локальная книга. Онлайн-синхронизация, сотрудники, покупки/подписки и защищённые автоматические копии не встроены. Физический запуск, визуальная и регрессионная проверка на устройстве требуют отдельной приёмки; успешная сборка APK её не заменяет.
