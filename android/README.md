# Android-сборка «Расчёта»

Приложение открывает общую книгу в системном браузере. Вход, подписка и данные находятся на сервере. Для работы нужен интернет. Сборка использует новый идентификатор пакета и устанавливается рядом с автономной «Долговой книгой». Импорт локальных записей пока недоступен.

Нужны JDK 17, Android SDK 35 и Gradle 8.11.1. Задайте `RASCHET_ORIGIN` равным HTTPS origin проверенного сервера без завершающего слеша. Из корня репозитория выполните:

```sh
gradle -p android lintDebug assembleDebug --no-daemon "-PraschetOrigin=${RASCHET_ORIGIN:?}"
```

Файл `android/app/build/outputs/apk/debug/app-debug.apk` подписан отладочным ключом. Для проверки сборки без развёрнутого сервера можно опустить аргумент `-PraschetOrigin`. В таком APK кнопка открытия отключена. Публикация клиентского APK требует рабочего адреса и настройки релизной подписи.

Настройка сервера описана в [server/README.md](../server/README.md).

Для ручной сборки в GitHub Actions используйте workflow **Android APK**. Публичный адрес берётся из переменной репозитория `RASCHET_ORIGIN`. Без неё workflow создаёт только проверочный APK. GitHub хранит его как артефакт **Raschet-debug**.
