# Экспериментальное серверное ядро

Это изолированный прототип доменной модели, не сетевой сервис и не готовая авторизация. Node.js 24 с `node:sqlite`, без сторонних зависимостей. `actor` должен предоставляться проверенным серверным провайдером идентификации; пользовательскому вводу доверять нельзя. Интеграция с интерфейсом отсутствует. Не использовать с реальными клиентами и не публиковать как production API.

Доступные операции: создать магазин и владельца, добавить участника владельцем, создать клиента, записать долг/оплату, просмотреть журнал, создать копию SQLite. Идентификатор операции и хеш полезной нагрузки позволяют повторить идентичную операцию без двойной записи; тот же идентификатор с изменённой нагрузкой отклоняется. Транзакция проверяет членство и остаток перед записью. Суммы — целые копейки.

Запуск изолированных тестов: `node --test tests/*.test.js`. Тест создаёт временную базу, два магазина и фиктивные личности, проверяет роли, границы магазинов, повтор операции, запрет переплаты и чтение восстановленной копии, затем очищает временный каталог.

Остаются: проверенная аутентификация и доступ по сети; управление участниками и отзыв; журнал событий участников; отмены и совместимость с локальным форматом v1/v2; очередь без сети, конкурентная синхронизация, конфликт данных; регулярное резервирование, проверка целостности и восстановление; шифрование, эксплуатационные настройки, миграции и негативные интеграционные тесты. SQLite в этой изолированной проверке не является решением для распределённой многосерверной системы.
