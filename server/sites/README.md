# Экспериментальный слой книги для Sites

Серверный модуль `book-api.js` принимает D1-совместимый адаптер и проверенный Sites dispatch заголовок `oai-authenticated-user-id`. Он не должен получать запросы в обход доверенного dispatch: иначе клиент может подделать идентификатор. Для каждого владельца хранится одна книга, а конкурентные записи проверяются по номеру версии в одной SQL-операции. Повтор последнего идентичного запроса с тем же requestId возвращает исходный результат; устаревшая версия или конфликт — HTTP 409. Валидация использует тот же `validateBook`, что и локальная книга.

`schema.sql` — предложение отдельной миграции схемы; она ещё не применена в Sites. `tests/sites-api.test.js` исполняет SQL на настоящем SQLite через небольшой адаптер D1 и проверяет изоляцию владельцев, Origin, повторы, конфликт версий и неверную книгу. Это не тест D1, аутентификации Sites, двух реальных аккаунтов или развёрнутого приложения.

Состояние: модуль не подключён к Worker и UI, данные не синхронизируются. Для приёмки остаются: миграции и сборка Worker по официальному workflow Sites; проверка, что dispatch гарантированно заменяет заголовок идентификации; фактические интеграционные проверки D1 и двух идентичностей; ручной экспорт и восстановление копий с сохранением локальных данных; проверка больших книг, повторов при сетевых отказах, аварийных ошибок и хранения; подключение UI с явным выбором версии при конфликте. Совместная работа сотрудников, очередь без сети и автоматические резервные копии этим модулем не реализованы. Не использовать реальные данные до прохождения проверок.

Ограничение нормализованной книги — 1 900 000 байт, чтобы уложиться в лимит D1 на размер строки 2 000 000 байт с запасом на метаданные. Слишком большая книга получает HTTP 413 до изменения данных. Старые записи и клиенты при обычной записи нельзя удалять или менять; переименовывать клиента можно. Восстановление более старой копии должно выполняться отдельным проверяемым сценарием, которого пока нет. См. [аудит прототипа в истории Git](https://github.com/lolokeksu09/dolg-book/blob/e36eeb8f9fb9ab0c9de702b737687c82e6f5d167/docs/AUDIT.md).
